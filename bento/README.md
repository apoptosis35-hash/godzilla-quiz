# おべんとうポン！

おかずを落として、同じおかず同士をくっつけて合体させる物理演算パズルです。iPhoneのSafariで遊ぶことを最優先に作っています(PCでも遊べます)。

- 起動方法: このリポジトリを静的Webサーバーで配信して `bento/` を開くだけです。ビルドはいりません。
  - 例: リポジトリ直下で `python3 -m http.server 8000` を実行し、`http://localhost:8000/bento/` を開く
  - GitHub Pagesで公開している場合のURLは `https://<ユーザー名>.github.io/godzilla-quiz/bento/` です
- iPhone: Safariで開き、共有メニューの「ホーム画面に追加」を選ぶと全画面のアプリとして起動します。一度開けばオフラインでも遊べます。

## 遊び方

- 指で左右に動かして落とす位置を決め、指をはなすとおかずが落ちます。点線のガイドと丸い印が、着地する位置を示します。
- 同じおかずがくっつくと、1段階大きなおかずに進化します(全11段階)。
  えだまめ → ミニトマト → たまごやき → タコさんウインナー → シュウマイ → からあげ → エビフライ → コロッケ → ハンバーグ → おにぎり → おべんとう王
- 合体で生まれたおかずがさらに合体すると「れんさ」になります。3れんさで特別演出、5れんさでフィーバー(スコア1.5倍)になります。
- おべんとう王どうしを合体させると、2つとも消えて大ボーナスが入ります。
- おかずが箱のふちより上に約2.3秒はみ出したままになるとゲームオーバーです。

## 機能

- 物理演算: Matter.js 0.20(1/60秒の固定ステップ、1ステップを2回に分けて計算)。画面サイズに関係なく、同じ「ワールド座標」で計算します。
- 演出: 合体の瞬間にキャラが中央へ吸い込まれて縮み、新しいキャラが弾むように登場します。星・ハート・キラキラ・光のリング・得点表示・画面のゆれ・フラッシュもあります。
- 連鎖: 合体音の音階が連鎖ごとに上がります。3れんさ以上でバナーとファンファーレ、5れんさ以上でフィーバーになり、BGMも華やかになります。
- キャラクター: オリジナルのおかず11種を、プログラムで描いています。表情は7種類(ふつう・まばたき・びっくり・ぎゅっ・にっこり・しょんぼり・あせり)です。
- 記録(localStorage): ハイスコア、最大れんさ、プレイ回数、図鑑の発見状況、設定を保存します。プレイ中のゲームもアプリを閉じたときに自動で保存し、「つづきから」で再開できます。
- 画面: タイトル、プレイ、結果(称号つき)、おかず図鑑、設定があります。
- 設定: BGM、効果音、振動、画面のゆれ、演出のひかえめモードを切り替えられます。
- サウンド: すべてWeb Audioで合成したオリジナルです(音声ファイルは使っていません)。最初にタップしたときに鳴り始め、iPhoneのマナーモードに従います。
- 振動: Vibration APIに対応した端末で振動します。iPhoneはSafari 18以降の仕組みを使って、軽い触覚フィードバックを試みます。
- 動作が重い端末では、描画解像度とパーティクルの数を自動で下げます。

## テスト

```sh
cd bento
npm test                      # ロジックの自動テスト(Node標準のテストランナー)
npx http-server -p 8123 ..    # 別の端末で、リポジトリ直下を配信
node tests/e2e.mjs http://localhost:8123/bento/   # iPhone相当のブラウザでのE2Eテスト(Playwrightが必要)
```

## ファイル構成

| ファイル | 内容 |
|---|---|
| `js/config.js` | 調整用の数値(物理、ルール、11種のサイズと得点、称号) |
| `js/game.js` | ゲームの中核(物理、合体、連鎖、スコア、ゲームオーバー、保存と復元)。DOMに依存しません |
| `js/render.js` | Canvas描画(お弁当箱、キャラクター、お箸、ガイド線) |
| `js/chars.js` | 11種のキャラクターと7種の表情の描画、スプライトのキャッシュ |
| `js/fx.js` | パーティクル、光のリング、得点表示、画面のゆれ |
| `js/audio.js` | 効果音とBGMの合成、振動 |
| `js/main.js` | 画面遷移、入力、HUD、図鑑、設定 |
| `tools/` | キャラクター一覧の確認ページと、アプリアイコンを作るページ |

外部ライブラリは Matter.js のみです(MIT License、`vendor/MATTER-LICENSE.txt`)。
