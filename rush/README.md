# ゲートラッシュ（GATE RUSH）

広告でよく見る「×2」「+10」のゲートを選んで仲間を増やし、敵の群れとボスを倒していくランナーゲームです。iPhoneのSafari向け（PCでも遊べます）。

- 起動方法：リポジトリ直下で `python3 -m http.server 8000` を実行し、`http://localhost:8000/rush/` を開くだけ。ビルド不要。
- GitHub Pages：`https://<ユーザー名>.github.io/godzilla-quiz/rush/`
- iPhone：Safariの共有メニュー →「ホーム画面に追加」で全画面アプリ（PWA）として起動。一度開けばオフラインでも遊べます。
- セーブは端末内（localStorage）。広告・課金・外部通信なし。

## 遊び方

画面を左右にドラッグして群衆を動かし、良いほうのゲートをくぐります。

| 要素 | 内容 |
|---|---|
| ゲート | `+` `×` は青・金、`−` `÷` は赤。どちらが得かは今の人数しだい（10人なら+30、100人なら×2）。良いほうを選ぶと **PERFECT**、連続でコンボ。 |
| 動くゲート | 片側だけを左右に動くゲート。追いかけて通過すると大きく増える。外すと MISS。 |
| 敵の群れ | 赤い群れとぶつかると1対1で相打ち。人数が足りないと全滅。 |
| 障害物 | 回転バーと丸ノコ。巻き込まれた仲間が減る（1つの障害物で減るのは最大約2割）。 |
| ボス | ゴール前の巨大な王冠ボス。HP（人数）以上で突っ込めば勝ち。 |
| ゴール階段 | 1段ごとに数人が残りながら登る。たどり着いた段の倍率（×1.2〜×6.0）で報酬が増える。 |
| ボーナスルーレット | クリア後、左右に動く針を止めて報酬を ×2／×3／×5。 |
| 強化 | コインで「人数（スタート人数+3）」「収入（報酬+15%）」を強化。 |
| ボーナスステージ | 5面ごと。敵なし・増えるゲートだけで数千人規模に。 |

負けたときは「あと◯人で勝てた！」と進行度を表示します。

## しくみ

- `js/level.js`：シード付き乱数でレベルを生成（レベル番号ごとに毎回同じ）。毎回良いほうを選べば、基本の8人スタートでもボスに勝てるよう、ゲートの数値・敵の人数・ボスHP・階段のコストを「その時点の最善人数」から決めています。
- `js/game.js`：Canvas 2D の疑似3D描画。群衆はひまわり配置（黄金角）で並び、表示は最大240人（人数はそれ以上も計算）。
- `js/audio.js`：効果音はすべて WebAudio で合成。
- `js/main.js`：画面遷移・セーブ・強化・ルーレット。

## テスト

```sh
cd rush
npm test                       # レベル生成のユニットテスト（1〜200面がすべてクリア可能か等）
npx http-server -p 8123 ..     # 別ターミナルで
node tests/e2e.mjs             # iPhone 13 エミュレーションでの通しプレイ（Playwright）
```
