# ブランコ大ジャンプ

ブランコをこいで、いちばん遠くまでとぶ3Dゲーム(three.js r169, MIT)。

- **こぐ**:ブランコがいちばん下にきたときにタップ(パーフェクト/グッド)。うまくこぐと一回転も。
- **とぶ!**:前にのぼっていくときにおす。ななめ45°くらいがねらいめ。
- 空中で長おし=グライド。コイン・スター・ふうせん(上にジャンプ)・トランポリンをねらう。
- コインでショップのパワーアップ(こぐ力/ジャンプ力/グライド/バウンド/じかん/じしゃく)。ミッション3つ常時。
- キーボード:スペース=こぐ・グライド / Enter・↑=とぶ
- 制限時間25秒。風(→ おいかぜ / ← むかいかぜ)がラウンドごとに変わる。ベスト記録は端末に保存。

`buranko/index.html` をそのまま静的サーバで開けば遊べます。

## 気持ちよさ・やりこみ
- パーフェクトジャンプ(メーターの赤い帯でとぶ)でスローモーション+加速。着地・トランポリン・ふうせんで画面ゆれ、パーティクル、スマホ振動。
- コインを続けて取ると音程が上がる。空中に ひこうきぐも、スピードで視野が広がる、10mごとのカウント音。
- ステージ:こうえん → ゆうやけビーチ(40m) → よるのまち(90m、コイン2倍) → くものうえ(160m、低重力)。ベストはステージごと。
- ランダムイベント(コイン2倍・ふうせんまつり・トランポリンまつり・おいかぜ・ゴールデンタイム・リングまつり)、ブーストリング。
- きせかえ6種(ひこうきぐもの色つき)、ログインボーナス(連続日数で増える)。
