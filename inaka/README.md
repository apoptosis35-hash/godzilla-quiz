# いなかのなつやすみ

麦わら帽子の子どもになって、夏休みの田舎の村を探検する3Dゲームです。朝8時から18時のチャイムが鳴るまで(約7分)に、村のあちこちで「なつやすみスタンプ」を集めます。iPhoneのSafariとPCで遊べます。

- 起動方法: リポジトリ直下で `python3 -m http.server 8000` を実行し、`http://localhost:8000/inaka/` を開くだけです。ビルドはいりません。
- GitHub Pages: `https://<ユーザー名>.github.io/godzilla-quiz/inaka/`
- iPhone: Safariの共有メニューから「ホーム画面に追加」を選ぶと、全画面のアプリ(PWA)として起動します。一度開けばオフラインでも遊べます。横向きがおすすめです。
- 記録(遊んだ日数・最高ポイント)は端末内(localStorage)だけに保存します。広告・課金・外部通信はありません。

## 遊び方

| 操作 | スマホ | PC |
|---|---|---|
| 歩く | 画面の左半分をドラッグ(スティックが出ます) | WASD / 矢印キー |
| 走る | — | Shift |
| 見まわす | 画面の右半分を左右にスワイプ | Q / C |
| しらべる・話す | 右下の黄色いボタン(近くに何かあると出ます) | Space / E / Enter |

- 右上のミニマップの黄色い点が、まだもらっていないスタンプの場所です。左上の 📒 を押すと、スタンプカードとヒントが見られます。
- 道に落ちている10円玉を拾うと、お菓子やジュースが買えます。
- 18時になると夕方のチャイムが鳴り、その日の「えにっき」とポイントが出ます。ポイントは「スタンプ×100 + カブトムシ×30 + 残ったお金」です。

## しくみ

- 3Dモデルは、すべて `../inaka-assets/`(Blenderで作った田舎3Dモデル集)のものを読み込んでいます。three.js r169 も、そこにある `vendor/` を使います。
  - プレイヤーの子どもは腕と脚が別の部品になっているので、歩くと手足を振ります。水車の車輪も回ります。
- `js/world.js`: 村の配置、当たり判定(回転した箱と円)、歩ける高さ(石段・神社の台地・橋・駅のホーム)、時間帯による空と光、電車の運行、動物の動き
- `js/main.js`: プレイヤーとカメラ(建物の中に入らないように近づく)、スタンプ・お金・カブトムシ、ミニマップ、えにっき
- `js/input.js`: キーボードとタッチ(仮想スティック・スワイプ)
- `js/audio.js`: 音はすべてWebAudioで合成しています(ミンミンゼミ、夕方のヒグラシ、川の音、足音、動物の鳴き声、電車、神社の鈴、ウェストミンスターの鐘の夕方チャイム)
- `tools/make_icons.py`: モデルを並べてBlenderでアプリのアイコンを描きます(`pip install bpy pillow`)

## テスト

ヘッドレスのChromium(WebGLはSwiftShader)で、iPhone 13の横向きを再現して確認しています。

```
python3 -m http.server 8123   # リポジトリ直下で
node inaka/tests/e2e.mjs http://localhost:8123/inaka/ [スクリーンショットの保存先]
```

確認している内容: モデルの読み込み、仮想スティックで歩ける、家の壁を通り抜けられない、お金が足りないと買えない、駄菓子・スイカ・川・神社(台地の高さ)・電車のスタンプ、18時のえにっき、次の日を始められる、コンソールにエラーが出ない。

**実機(iPhone)での動作とフレームレートは、まだ確認していません。** スマホでは影を切り、解像度を少し下げています。
