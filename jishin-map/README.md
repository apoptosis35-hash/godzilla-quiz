# 日本の地震リスクマップ

日本のどこで強い揺れのリスクが高いかを、1枚の地図で拡大しながら確認できるWebアプリです。ビルド不要。

- 起動：リポジトリ直下で `python3 -m http.server 8000` → `http://localhost:8000/jishin-map/`（`index.html` を直接開いても動きます）
- GitHub Pages：`https://<ユーザー名>.github.io/godzilla-quiz/jishin-map/`
- PC・スマホ対応（スマホはパネルを下から引き出す形）

## できること

| 機能 | 内容 |
|---|---|
| 揺れの確率地図 | J-SHIS（防災科研）の確率論的地震動予測地図を約250mメッシュで表示。震度5弱/5強/6弱/6強以上を切り替え、透明度も調整可 |
| 想定震源域 | 南海トラフ、首都直下、日本海溝・千島海溝の各領域、日向灘など15領域と30年発生確率（2026年1月1日算定の公表値ベース） |
| 主要活断層帯 | Sランク（30年確率3%以上）を中心に22断層帯（概略位置）。国土地理院「活断層図」レイヤーで詳細も確認可 |
| 地点を調べる | 地図タップ・住所検索・現在地で、その地点の揺れの確率（4段階）、地盤の揺れやすさ（増幅率・AVS30・微地形）、近くの想定震源を表示 |
| ランキング | 47都道府県庁所在地の「30年以内に震度6弱以上」確率（全国地震動予測地図2020年版） |
| 過去の地震 | 主な被害地震23件（1891年濃尾〜2025年青森県東方沖）＋USGSのM5.5以上（1990年〜） |
| 津波 | ハザードマップポータルの津波浸水想定を重ねて表示 |

表示位置はURL（`#ズーム/緯度/経度`）に保存されるので、そのまま共有できます。

## データ出典

- J-SHIS 地震ハザードステーション（防災科学技術研究所）— WMS・Web API
- 地震調査研究推進本部「長期評価による地震発生確率値の更新について」（2026年1月公表）、「南海トラフの地震活動の長期評価（第二版一部改訂）」（2025年9月）、「全国地震動予測地図2020年版」
- 国土地理院 地理院タイル（淡色・標準・写真・陰影起伏・活断層図）、ハザードマップポータル
- USGS Earthquake Catalog

想定震源域と活断層の線は位置関係を示す概略図です。確率は毎年更新されるので、正確な値は出典を確認してください。地図ライブラリは Leaflet 1.9.4（`vendor/` に同梱、BSD-2-Clause）。
