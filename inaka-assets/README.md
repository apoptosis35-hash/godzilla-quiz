# 田舎3Dモデル集(inaka-assets)

田舎ゲームを作るときに使うための、ローポリ3Dモデルのストックです(全54種)。これを使ったゲーム「いなかのなつやすみ」が `../inaka/` にあります。すべて Blender の Python スクリプトで作った、オリジナルのモデルです。

- 一覧と3Dプレビュー: `inaka-assets/index.html`(GitHub Pages なら `https://<ユーザー名>.github.io/godzilla-quiz/inaka-assets/`)
  - カードを押すと、モデルを3Dで回して見られます。GLBのダウンロードもできます。
  - 「村に並べてみる」で、全モデルを実寸で並べたサンプルの村を表示します。

## 決まりごと(ゲームで使うとき)

- 形式: glTF バイナリ(`glb/*.glb`)。three.js なら `GLTFLoader` でそのまま読み込めます(`vendor/` に three.js r169 一式があります)。
- 大きさ: **1単位 = 1m** の実寸です。拡大縮小しなくても、モデル同士の大きさがそろっています。
- 向き: Y軸が上、正面は +Z です。原点は足元の中央で、地面(y = 0)に置くとそのまま立ちます。
- 見た目: テクスチャを使わず、共通の色パレット(`tools/make_models.py` の `PALETTE`)の単色マテリアルだけを使っています。同じ色はモデルをまたいで同じ名前なので、まとめて色を変えたり、描画をまとめたりしやすくしています。
- 発光するのは、自動販売機の明かり・軽トラのライト・石灯籠の火袋だけです(emissive)。
- 1モデルはおよそ50〜1500三角形と軽量で、スマホでもたくさん置けます。
- 動かしたい部品があるモデル(子ども・水車)は、部品ごとに別のノードになっています。原点が関節や軸の位置にあるので、`getObjectByName('kodomo_arm_l')` などで取り出して回すだけで動きます。

## 作り直す・追加する

Blender 5.2 で、次のどちらかを実行します。

```
pip install bpy
python3 tools/make_models.py --render          # 全部作り直す(プレビュー画像も)
python3 tools/make_models.py --render kura ido # 指定したモデルだけ
# または: blender -b -P tools/make_models.py -- --render
```

- 出力: `glb/<名前>.glb`、`preview/<名前>.jpg`、`models.json`、`tools/inaka.blend`(Blenderで開いて手直しできます。全部作り直したときだけ全モデルが入ります)
- モデルを追加するときは、`tools/make_models.py` に `@model('名前', '日本語名', '分類')` をつけた関数を書きます。動かす部品は `part('名前', 軸の位置)` のあとに作ります。`box` / `cyl` / `ico` / `prism` / `gable`(切妻屋根)/ `hip`(寄棟屋根)などの部品関数を組み合わせて作ります。
- 「村に並べてみる」の配置は `index.html` の `LAYOUT` です。
