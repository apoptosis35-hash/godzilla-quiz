# 海凪の港町(UMINAGI PORT TOWN)

どうぶつの住人たちが暮らす日本の小さな港町で、魚つり・虫とり・化石ほり・住人とのおしゃべりを楽しむ、のんびりしたスローライフ3Dゲームです(オリジナル作品。キャラクター・名前・せりふはすべてこのゲームのオリジナルです)。港の魚市場や桟橋、坂道の商店街、石垣と石段が続く丘の住宅街、海凪神社、崖の遊歩道、白い灯台の立つ丘の展望台まで、途切れずに歩いて行けます。iPhone の Safari と PC のブラウザで動きます。

- 起動方法: リポジトリ直下で `python3 -m http.server 8000` を実行し、`http://localhost:8000/uminagi/` を開くだけです(ビルド不要)。
- GitHub Pages: `https://<ユーザー名>.github.io/godzilla-quiz/uminagi/`
- iPhone: Safari の共有メニューから「ホーム画面に追加」で全画面のアプリ(PWA)になります。一度開けばオフラインでも遊べます。**横向きがおすすめ**です(縦向きでも遊べます)。
- 町の建物・船・小物はすべて `../uminagi-assets/`(Blender で作った港町3Dモデル集)のモデルです。

江ノ島のような雰囲気の港町です。道路は現実の日本の町に合わせ、白線・横断歩道・側溝のふた、ブロック塀、止まれ・制限速度・駐車禁止の標識、カーブミラー、ガードレール、信号機、バス停、駐車場の車を置き、車は町をひと回りする道を両方向に左側通行で走ります(トンネル → 海沿いの道路 → 港の道 → 商店街 → 広場 → 東の丘の坂道 → 港 → トンネル)。曲がり角はなめらかに曲がって手前で減速し、曲がる前にはウインカーを出します。交差点では先に入った車を待ち、前の車との車間を保ちます。トンネルは中に入ると照明が並び、少し奥の「歩行者通行止め」の柵まで歩けます。横断歩道の信号は青・黄・赤と変わり、車は赤で止まり、人やプレイヤーの前でも止まります。東の丘には港から上る坂道と3本の路地があり、上の町の家はすべて道に面して建っています。海の向こうに富士山、丘の上にシーキャンドル風の展望灯台、参道入口の大鳥居、ヨットハーバー、パラソルの並ぶ海水浴場、空を舞うトンビ、しらす丼やたこせんべいの立て看板があります。砂浜からは長い弁天橋で小さな島「凪ノ島」へ渡れ(頂上に小さな神社と展望スポット)、海沿いには緑とクリーム色の路面電車が駅と線路の端を行き来しています(屋根に乗ることもできます)。

操作するのは港町の豆柴 **「なぎ」**(このゲームのオリジナルキャラクター)。赤毛に白い裏白(頬・口元・胸・足先)、麻呂眉、ピンと立った三角耳、背中に巻いた巻き尾、紺地に白い波模様のバンダナの2頭身の柴犬です。歩く・走る(腕を振って前傾)・待機(呼吸、きょろきょろ、耳がぴくっと動く、しっぽを振る)・段差から落ちるとき(手足を広げて耳がなびく)・着地の踏ん張りのモーションがあります。ジャンプや壁登りはありません。

## 港町のくらし

**はじめは何もない入り江**から始まります。あるのは草地の岸と、たぬきのあらたの屋台、ねこのツムギとくまのおもちのテントだけ。魚や虫を売ってナギをため、あらたの「町づくり」で 漁港・東の浜・道路と電柱・商店街・丘の住宅街・海凪神社と資料館・灯台の丘・海辺の電車・弁天橋と凪ノ島 をたのむと、**ひと晩で(次の朝5時すぎに)**できあがり、新しい住人が引っこしてきます。図鑑が5種類になると、あらたがふくろうの学者ほうさくさんを呼んでくれます(神社ができるまではテント暮らし)。URL に `?town=all` を付けると、全部できあがった町を見られます。

時間は端末の**ほんとうの時計**と同じです(⚙️ の「今の時間」。昼・夕方・夜に固定もできます)。毎朝5時に新しい一日になり、化石のヒビ・ナギの出る岩・浜辺の貝と手紙入りの瓶・みかんの実が入れかわります。地面は遠くほど丸く沈む「まるい地平線」で描いています(⚙️ で切り替え)。

- **住人**: ねこのツムギ(漁港)、うさぎのももか(商店街)、くまのおもち(住宅街)、ペンギンのしおん(桟橋)、かえるのガンテツ(東の浜)、りすのことは(坂の上の広場)。性格ごとに口ぐせと話し方がちがい、時間帯・季節・さっき釣った魚の話をします。一日に一度話しかけたり、プレゼントをあげると仲よし度が上がり、仲よしになるとお返しをくれることもあります。近づくと手をふってくれます。
- **つり**: つりざおを持って水ぎわで A。海に見える魚の影が浮きに寄ってきて、何度かつついたあと**グッと沈んだ瞬間に A**。早すぎても遅すぎても逃げられます。走って近づくと影が逃げます。魚は30種類で、場所(港・沖・浜)・月・時間で釣れるものが変わり、影の大きさで魚の大きさがわかります。
- **虫とり**: あみを持って A を**押しっぱなしにすると、そーっと歩き**、離すとあみをふります。走ったり速く近づくと逃げます。30種類(花・木の幹・地面・岩・水辺・浜・空中)。
- **ほる・ゆする**: スコップで地面のヒビをほると化石(神社のほうさくさんに鑑定してもらう)やナギの袋。毎日ひとつの岩はスコップでたたくとナギが出ます。みかんの木をゆすると実が落ち、ふつうの木からは枝やナギが落ちることも。浜辺では貝がらと手紙入りの瓶がひろえます。
- **海凪商店**(はじめは岸の屋台、商店街ができると商店街へ。たぬきのあらた): 魚・虫・貝・果物を買いとり(まとめて売るもできます)、スコップなどの道具を売り、町づくりの注文を受けます。お金の単位は「ナギ」。
- **海凪資料館**(神社、ふくろうのほうさく。神社ができるまではテント): 魚・虫・化石を寄贈できます。図鑑(📖)で見つけたもの・寄贈したものを確認できます。
- **なぎの家**: はじめは東の岸壁のテント。あらたの「町づくり → なぎの家」(20,000 ナギ)でひと晩で家になります。入口で A で中に入り、ポケットの家具を「置く」で並べ、家具の前で A で まわす / しまう。家具は65種(和室・海辺・カフェ・部屋・庭のシリーズ)で、外にも置けます(柵・ベンチ・井戸・ブランコ・たき火など)。家の横のポストには住人からの手紙とプレゼントが届きます。
- **DIY**: 木の枝・木材(おので木を切る、1本の木から1日3つ)・石と鉄のかけら(スコップで岩をたたく)・星のかけら・ゆきのけっしょうを集め、あらたの屋台の「DIY」や作業台でレシピの品を作ります。レシピは瓶の手紙や仲よしの住人から増えます。道具は使うとこわれます(網・竿30回、スコップ・おの40回)。
- **天気と季節**: 毎日 晴れ・くもり・雨(冬は雪)が変わり、雨の日だけの魚や虫がいます。秋は葉が色づき、桜は春だけ咲きます。10月20〜31日はかぼちゃランタン、8月の日曜の夜は花火。晴れた夜には流れ星が流れ、A で願うと次の朝 浜に星のかけらが落ちています。住人の誕生日には特別なあいさつがあり、プレゼントで大きく仲よくなれます。
- **住人とのくらし**: 毎日だれか一人が「❗」を出して頼みごと(魚・虫・みかん・貝がら・木材)をします。住人どうしでおしゃべりし、夜(23〜6時)は家に帰ります。住人のテントや家の入口で A で遊びに行けます。
- **毎日のお店**: 品物は日替わり(家具3つ・服1つ、たね、道具)。日曜の朝だけ だいこんを買え、平日は値段が朝と昼で変わります(次の日曜までに売らないとだめになります)。ときどき旅ねこのミケが珍しい品を持ってきます。
- **収集**: 魚65種・虫65種・磯の生き物30種(浜の岩場の✨を A で調べる)・化石24種・美術品20点(全204点)。資料館では「展示室を見る」で、寄贈したものが台に並び、絵は壁にかかった部屋に入れます。
- **美術品**: 絵はゲームの中で1枚ずつ描かれます。旅ねこのミケが売りに来ますが、ときどき「にせもの」(色が違い、左右が反対)が混ざっていて、ほうさくさんは本物しか受け取りません。買った絵はイーゼルに飾れ、ポケットの「見る」でながめられます。
- **服**: バンダナの色と帽子(麦わら・キャップ・ニット)。ポケットで「身につける」、👒ボタンで帽子を外します。
- **植える**: たねは2日で花が咲き、みかんを植えると3日で実のなる木になります(スコップで ほりかえせます)。
- 天気は URL に `?weather=rain` / `snow` / `cloudy` / `clear` を付けて試せます。
- ポケットは20マス。くらしのデータ(お金・ポケット・図鑑・仲よし度)は端末内(localStorage `uminagi_life_v1`)に保存されます。

## 画面と表現

- **海**: 水面の手前に描かれた景色(海底・岩・岸壁・桟橋の杭)を画面からコピーして、波で屈折させて透かします。水深と視線の角度に応じた光の吸収(Beer–Lambert。赤から先に消える)で、浅瀬は透明なエメラルド、深いほど青。港の中は水深4〜6mの砂地に岩と海藻が見え、海底には揺れるコースティクス。港内は穏やか、外海はうねり。空の映り込み(フレネル)、太陽のきらめき、岩やテトラポッドに当たる白波。漁船は同じ波の式で揺れます(屈折は標準以上。軽量は半透明の合成)。
- **遠景**: 尾根と岩の海岸線・森のある島々と、水平線に3層の山並み。遠いものほど空気の色に霞みます(専用のかすみ表現)。
- **光**: 昼・夕方・夜を2.5秒かけて切り替え。太陽の向き・色、空のグラデーション、雲、夜の星、霧の色が変わり、環境の映り込み(PMREM)も作り直します。夜は提灯・街灯・石灯籠・自販機・窓の明かり・灯台が光ります。
- **影**: プレイヤーの周り(標準45m・高画質60m)に太陽の影。影の範囲はプレイヤーについていき、テクセルにそろえてちらつきを抑えています。
- **材質**: 木・漆喰・瓦・石垣・コンクリート・トタン・アスファルト・石畳などはタイル状のPBRテクスチャ(色+法線)。魚市場まわりの地面は水たまりの粗さマップで濡れて光ります。地形は傾きで草・土・岩、海辺は砂を混ぜるシェーダーです。
- **自然**: 木と植え込みは、葉の房を描いた透過テクスチャ(広葉・松葉・桜・低木)の板を樹冠のまわりに重ねた「葉カード」方式で、陰影は樹冠の中心から外向き。葉・草・網は風で揺れます(頂点シェーダー)。山の森(標準で木1800本)、崖に生える低木と岩、遠くの島々。カモメが港の上を飛び、町には漁師・お店の人・町の人・猫が歩いています。
- **音**: WebAudio で合成した波の音(海に近いほど大きい)、カモメの声、足音(石・土で違う)、夜の虫の声。

## PC 向け「最高(PC)」画質

PC のブラウザで開くと初期値が **最高(PC)** になります(`?q=ultra` でも指定可)。スマホ向けの設定に加えて:

- **ポストプロセス**: GTAO(地面と建物の接地面・軒下・路地の環境遮蔽)→ ブルーム(夜の街灯・提灯・窓、夕日のきらめき。時間帯で強さが変わる)→ トーンマッピング → SMAA(アンチエイリアス)。HDR の NaN と強すぎる光は事前に除いて、光のにじみが画面に広がらないようにしています。
- **テクスチャ 1024px**(`../uminagi-assets/textures/1k/`、同じ柄の2倍解像度、異方性フィルタ16倍)
- **影 4096px を半径90m**、街の灯りの点光源 12個
- **木 約2800本・草 9000株**、建物の詳細モデルを約165m先まで、木の詳細モデルを約100m先まで表示
- 描画解像度は画面の解像度(最大2倍)のまま

### 歩ける場所のルール(`player.js`)

- 地面の高さは「台」(岸壁・道・段々・階段・桟橋…)があればその式、なければ自然の地形。0.6m を超える段差は登れず(石垣・岸壁は壁になる)、階段と坂はそのまま上り下りできます。
- 自然の斜面は傾きが約46°を超えると登れません。台から台へは飛び降りられますが、崖や海へは降りられません(海に落ちない)。
- 建物・船・木・電柱・柵・小物は回転した箱か円の当たり判定で、壁に沿って滑ります。人とは押し合います。
- カメラはプレイヤーと自分の間に建物や地面があると近づきます。

### 描画の工夫(iPhone 向け)

- 同じモデルはすべて **GPU インスタンシング**。テクスチャの無い色だけのマテリアルは1つにまとめ(色・粗さ・金属度・発光は頂点属性)、同じテクスチャの部品も1つにまとめているので、家1種類あたりの描画は約8回です。
- **LOD**: 建物は近くで詳細(LOD0)、遠くで約30%に減らしてテクスチャも省いた LOD1。木は3段階(詳細 → 減らした形 → 約30三角形の代用形)。小物は遠くで消えます。LOD は1つずつの距離で切り替え、まとめて切り替えられるときは一括で行います。
- **視錐台カリング**: 小物は200m、自然物は128m の区画ごとにインスタンスをまとめ、区画ごとに画面外を省きます。
- **影**は近くの詳細なモデルだけが落とします(影の範囲 45〜60m に合わせる)。
- モデルは meshopt 圧縮+量子化(約9MB → 読み込み時に展開)。テクスチャは512pxのJPEGをミップマップ付きで使います。
- 画質は「軽量 / 標準 / 高画質」(解像度・影・木と草の数・LOD 距離)。スマホは標準、PCは高画質が初期値です(URL に `?q=low` などでも指定可)。
