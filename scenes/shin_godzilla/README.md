# シン・ゴジラ(第4形態)Blenderモデル

参考画像(曇り空を背に見上げたシン・ゴジラ)をもとに、Blenderで作った3Dモデルです。形・皮膚・赤い亀裂まで、すべてPythonスクリプトで組み立てています。

- 完成画像: `render.png`(1200×1600、Cycles)
- Blenderファイル: `shin_godzilla.blend`(開くとリメッシュと皮膚の凹凸が計算されるので、表示まで数秒かかります)

## 作り直す

```
pip install bpy
python3 make_model.py --preview          # 低解像度・少ないサンプル数で試しにレンダリング(約1分)
python3 make_model.py --preview --head   # 顔と手のアップで確認
python3 make_model.py                    # 本番(render.png と shin_godzilla.blend)
python3 export_glb.py                    # スマホ・Web用の shin_godzilla.glb と viewer/index.html
```

## iPhoneで見る

`viewer/index.html` は、指で回したり拡大したりできる3Dビューアです。外部のライブラリも別ファイルも使わず、モデルのデータをページに埋め込んで、WebGLで直接描いています(約2.2MB)。`export_glb.py` が `viewer/template.html` から作ります。
glTFやスマホのビューアには手続き的なシェーダーを入れられないので、皮膚の模様と赤い亀裂は頂点カラーに焼き込み、メッシュは約8万面まで減らしています。

## ゲーム「首都進撃」

`game/index.html` は、このモデルを操作して街を壊す3Dゲームです(iPhoneとPCで遊べます)。`export_glb.py` が `game/template.html` から、ビューアと同じモデルデータを埋め込んで作ります。外部のライブラリも通信も使いません。

- 120秒でできるだけ多くのビルを壊すと得点になります。ヘリのミサイルで体力が0になると「凍結」で終わります
- 操作: 左下をなぞって移動(WASD/矢印)、「熱線」を押している間に熱線(スペース)、「尻尾」で周りを薙ぎ払う(E)
- 低いビルは歩いて踏み潰せます。高いビルは熱線か尻尾で壊します

個人で楽しむためのファン作品です。ゴジラの名前やデザインは東宝の権利物なので、一般に公開・配布しないでください。

## 作り方

| 部分 | 内容 |
|---|---|
| 体 | メタボールの連なりで胴体・長い首・小さな頭・太い脚・小さな腕(手のひらを上に向けた長い指)・長い尾(後ろへ伸びてから上へ立ち上がる)を作り、口は負のメタボールでくり抜いています |
| 背びれ | 背骨に沿って、炎のようにギザギザした板を3列(中央が大きく、左右が小さい)並べています。首から背中で最大、尾の先へ向かって小さくなります |
| 一体化 | 体と背びれをまとめて、ボクセルのリメッシュ(`fuse`)とスムーズ(`soften`)で一つの肉の塊にしています |
| 皮膚 | ジオメトリノード `skin_folds_and_cracks` で、ケロイド状のこぶ・縦方向の盛り上がり・亀裂の溝を彫っています。マテリアル `shin_skin` が同じ模様から、黒い皮膚・明るく光る盛り上がり・溝の赤い発光を作ります |
| その他 | 不ぞろいな歯、小さな黒い目、足の爪 |

## 調整しやすい場所

- 皮膚の凹凸: モディファイア `skin` の入力 `Crack Depth`(溝の深さ)、`Lump Height`(こぶ)、`Fold Height`(盛り上がり)
- 赤い亀裂の太さ・量: `crack_net()` の `(1.3, 0.05), (4.0, 0.1)`(模様の細かさと線の太さ)
- 赤の光り方: `skin_material()` の `gs.inputs[1]`(発光の強さ)
- 細かさ: モディファイア `fuse` の `voxel_size`(小さいほど細かく重い)
- 向き: `rig_root` の回転(全体がまとめて回ります)
- カメラ: `camera_and_render()` の `cam.location` と `target`
