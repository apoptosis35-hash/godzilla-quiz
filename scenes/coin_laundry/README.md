# 深夜のコインランドリー(Blenderシーン)

雨の夜、通りに面したコインランドリーの店内を、Blenderで作ったシーンです。参考画像の雰囲気(蛍光灯の青白い光、ステンレスの洗濯機と乾燥機、ガラス越しの濡れた道路と街灯)をもとに、すべてPythonスクリプトで組み立てています。

- 完成画像: `render.png`(1536×1024、Cycles)
- 動画: `coin_laundry.mp4`(8秒・1280×720・24fps。ゆっくり店内へ進むカメラ、降り続く雨、奥の蛍光灯のちらつき)
- Blenderファイル: `coin_laundry.blend`(開いてカメラや照明を動かせます。看板の画像は `textures/` を参照します)

## 作り直す

```
pip install bpy pillow
python3 make_textures.py          # 看板・操作パネル・ステッカー・時計の画像(IPAゴシック)
python3 make_scene.py --preview   # 半分の解像度・少ないサンプル数で試しにレンダリング(約1分)
python3 make_scene.py             # 本番(render.png、CPUで十数分)
python3 make_video.py             # 動画(coin_laundry.mp4。192フレーム、CPUで約2時間。途中で止まっても再実行で続きから)
```

日本語フォントは IPAゴシック(`fonts-ipafont-gothic`)を使います。

## シーンの中身

| 場所 | 置いてあるもの |
|---|---|
| 左(通り側) | ガラス張りの店先とアルミの窓枠、ガラスの文字「コインランドリー 年中無休 6:00-24:00」、「開放厳禁」の貼り紙、アルミのベンチ、玄関マット、傘立て |
| 右 | 大型の洗濯乾燥機4台(操作パネル・容量の札・注意ステッカーつき)、上に「洗濯機の使い方」と「料金表」、奥に2段積みの乾燥機8台と「乾燥機」の表示 |
| 中央・奥 | たたみ台とワイヤーのカート、スタッフ用のドア(「関係者以外立入禁止」)、時計(23:40)、エアコン、壁の扇風機、貼り紙、小さなテーブルと洗濯かご・観葉植物、丸椅子 |
| 天井 | 蛍光灯4台(青白い光)、点検口 |
| 外 | 濡れた道路と歩道、家並みと明かりのついた窓、LEDとナトリウムの街灯、自動販売機の明かり、木のシルエット、雨すじ |

- 床はタイル模様に汚れと濡れたムラをつけ、場所によって光を映すようにしています。
- ガラスには雨粒の凹凸をつけています。

## 調整しやすい場所(`make_scene.py`)

- 明るさ: 蛍光灯は `ceiling_lights()` の `L.data.energy`、全体は `camera_and_render()` の `exposure`
- 街灯の強さ: `street()` の `L.data.energy`(強すぎると外が白く飛びます)
- カメラ: `camera_and_render()` の `cam.location` と `target`
- 画質と時間: `scene.cycles.samples`(本番160)
