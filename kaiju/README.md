# KAIJU FIGHTERS 巨獣大決戦

巨大怪獣を操作して戦う、ブラウザで動く本格3D対戦格闘ゲームです。iPhoneとPCの両方で遊べます。
(プロジェクト仮称「GODZILLA KAIJU FIGHTERS」の技術デモ版)

- 起動: このフォルダを静的Webサーバーで配信して `kaiju/index.html` を開くだけで遊べます。ビルド作業はいりません。
  - 例: リポジトリ直下で `python3 -m http.server 8000` → `http://localhost:8000/kaiju/`
- GitHub Pages で `main` を公開していれば、URLは `https://<ユーザー名>.github.io/godzilla-quiz/kaiju/` です。
- iPhone: Safariで開き、共有メニューの「ホーム画面に追加」を選ぶと、全画面のアプリとして起動します(PWA、オフライン対応)。

## 権利について(重要)

東宝の「ゴジラ」シリーズに登場する怪獣の名前・デザイン・音楽は、権利で保護されています。利用許諾が確認できなかったため、本作には**一切収録していません**。
代わりに、依頼された4つの戦闘スタイルを再現したオリジナル怪獣を作りました。

| 依頼のスタイル | 本作のオリジナル怪獣 |
|---|---|

| 高速空中機動・突進・エネルギー吸収・電撃 | **VESPERA ヴェスペラ**(4枚翅の昆虫型、毒針、吸収、落雷) |
| 3本の首・引力光線・翼の打撃 | **TRIVERN トライヴァーン**(三首二尾の竜、引力光線) |
| 高機動兵器・格闘・ミサイル・メーサー | **KUROGANE 鋼神クロガネ**(銀と黒の装甲メカ、ミサイル、メーサー) |
| 背びれがせり出す溜め熱線・一撃必殺 | **RAGNOS ラグノス**(着弾点ごと吹き飛ばす青い熱線) |
| 細身の格闘戦・蹴り技 | **VORTHAR ヴォルザ**(突進と蹴り、真紅の渦巻く熱線) |
| 背中からのレーザー・異様に高い背丈 | **MUTAGON ミュータゴン**(赤熱する亀裂、全方位レーザー、長い尾) |

- 正式な許諾が得られれば、同じ格闘システムに公式キャラクターを追加できる設計になっています。

## 操作方法

| 操作 | キーボード1P | キーボード2P | ゲームパッド | タッチ |
|---|---|---|---|---|
| 移動(左右=前後、上下=奥/手前へサイドステップ) | WASD | 矢印キー | スティック/十字キー | 左スティック |
| 弱攻撃 / 強攻撃 | U / I | テンキー 4 / 5 | X / Y | 弱 / 強 |
| 必殺技 | O | テンキー 6 | B | 必殺 |
| 掴み(投げ) | L | テンキー 3 | A | 掴 |
| ガード(後ろ入力でもガード) | J | テンキー 1 | RB / LT | ガード |
| 回避(無敵あり) | K | テンキー 2 | LB | 回避 |
| 超必殺技(ゲージ100%) | P | テンキー 0 | RT | 超必 |
| ポーズ | Esc | | START | Ⅱ |

- 前を2回入力するとダッシュ、後ろを2回でバックダッシュです。↓+ガードでしゃがみガードになります。
- キー割り当ては、設定画面からキーボード・ゲームパッドとも変更できます。
- タッチボタンは、大きさ・透明度・位置を変更できます。

## 実装済みの機能

- **3D怪獣8体(すべて完全に戦えます)**
  - 体はボーンとスキニングで動きます。胴・首・尾は、なめらかに曲がるスキンメッシュです。
  - 質感はPBRマテリアルと、生成した法線マップ(鱗・甲殻・装甲パネル)で表現しています。
  - 目や背板は発光し、尾は慣性で揺れます。
- **格闘システム**
  - 60fps固定のフレーム処理です。全技に発生・持続・硬直・ダメージ・リーチ・上中下段の属性があります。
  - 当たり判定は球、やられ判定は円柱で計算しています。
  - ガード(立ちは上中段、しゃがみは下段を防ぐ)と、側面・背後からの攻撃はガードできない仕組みがあります。
  - 無敵つきの回避とサイドステップで、光線もかわせます。
  - 投げと投げ抜け、L→L→Lの連携、キャンセルコンボ、浮かせからの空中追撃(ジャグル)があります。
  - コンボ補正、カウンターヒット、スーパーアーマー、ダウン追い打ち、受け身、起き上がり無敵も入っています。
- **必殺技の演出**
  - 光線は充填・照射・追尾・着弾爆発まで一連で動きます。光線同士の撃ち合い(相殺)もあります。
  - 飛び道具は誘導ミサイル、雷球、地割れ衝撃波、突風です。
  - 超必殺技では画面が止まり、専用カメラ・暗転・発光・スローモーションが入ります。KO時は専用演出になります。
- **ステージ5種**: 夜の首都、夕暮れの港湾、雨の工業地帯、火山地帯、廃墟都市
  - ビルは部分破壊・崩壊アニメーション・粉じん・破片・瓦礫が出ます。壊れた状態はラウンドをまたいで残ります。
  - 車は吹き飛んで爆発し、街灯は倒れます。地面にはひび割れが残ります。
  - 雨・雷、溶岩・噴火、炎・煙などの天候や環境演出もあります。
  - アリーナの外には、巨大な日用品(アヒル・ドーナツ・マグカップ・サボテン・目覚まし時計)が立っています。アヒルは港の海に浮かんで揺れ、時計の針は早回しで動き、マグカップからは湯気が出ます。
- **MY SOUNDS**: お手持ちの音声ファイルをBGM(メニュー・バトル・ボス戦)と各怪獣の咆哮に設定できます。ファイルは端末内(IndexedDB)にだけ保存されます。
- **ストーリーモード**: オリジナルの物語で全8章。会話シーンと章ごとのバトルがあり、クリアすると次の章が解放されます(会話中の怪獣名は、設定した表示名で表示されます)。
- **ゲームモード**
  - アーケード: 3戦のあと、最終ボス「GORVATH Ω」と戦います。進むほど難しくなります。
  - VS CPU: 難易度は EASY / NORMAL / HARD / VERY HARD の4段階です。
  - ローカル2人対戦: キーボード2人分、またはゲームパッド2台で遊べます。
  - トレーニング: CPUの動き(棒立ち・ガード・しゃがみガード・通常行動)を選べます。当たり判定の表示、フレームデータとコンボダメージの表示、ゲージ無限、位置リセットがあります。
- **キャラクター選択画面**
  - 16枠あり、うち12枠は開発中で選べません(ロック表示)。
  - 選んだ怪獣の3Dプレビュー(待機・勝利ポーズ・必殺技)、能力値、技名、長所と短所を表示します。
- **バトル画面の表示**: 体力ゲージ(遅れて減る赤ゲージつき)、超必殺ゲージ、タイマー、ラウンド勝利数、コンボ数とダメージ、ROUND / FIGHT / K.O. の演出、結果画面
- **ルール設定**: 制限時間(30・60・99秒・無制限)、勝利ラウンド数(1〜3本先取)
- **音響**: すべてWebAudioで合成しています。足音・打撃・光線・爆発・崩壊・咆哮(怪獣ごとに声質が違います)・UI音・ステージ別BGM・英語アナウンスがあります。
- **画質プリセット**: ULTRA / HIGH / MEDIUM / LOW / AUTO。FPSが落ちたときに解像度を自動で下げる機能もあります。
- **保存**: 設定と戦績(アーケードクリア数など)をIndexedDBに保存します。使えない環境ではlocalStorageに保存します。
- **PWA**: マニフェストとService Workerによるオフラインキャッシュ、ホーム画面アイコンがあります。

## 3Dモデル(Blender)

ステージの巨大な小物5種は、Blenderで作ったモデルです(`models/*.glb`、three.js の GLTFLoader で読み込み)。

- 作り方は `tools/blender/make_props.py` にすべて書いてあります。Blender 5.2 で次のどちらかを実行すると、作り直せます。
  - `pip install bpy` のあと `python3 tools/blender/make_props.py --render`
  - `blender -b -P tools/blender/make_props.py -- --render`
- 出力: `models/*.glb`(ゲーム用)、`tools/blender/props.blend`(Blenderで開いて編集できます)、`tools/blender/preview/*.png`(プレビュー画像)
- どのステージに何を置くかは `js/stage.js` の `props`、大きさと動きは `js/props.js` で決めています。

## 動作確認

ヘッドレスのChromium(SwiftShaderでWebGLを動かす環境)で、次の項目を自動テストして確認しました。

1. タイトルから開始できる
2. キャラクター選択が機能する
3. 3D怪獣4体が正常に表示される
4. 前後左右に移動できる
5. 攻撃が命中する
6. ガードと回避が機能する
7. 必殺技・超必殺技が発動する
8. CPUが行動する
9. 勝敗が決まる
10. 再戦・アーケードを最後まで進められる
11. iPhoneサイズ(844×390)でタッチ操作できる
12. 戦闘中に重大なエラーが出ない

あわせて、次の個別の挙動も確認済みです。

- ガードの上中下段の判定、投げ、光線の回避、壁に叩きつけたときのビル破壊、背後からの攻撃
- 4×4の全組み合わせでL→L→L連携がつながること
- CPU同士の全対戦が、エラーなく決着すること

**FPSは実機で計測していません。** ヘッドレス環境はGPUがないため、描画速度の参考になりません。参考値として、戦闘の計算処理(1フレーム分)は約0.1msで、描画以外の負荷はほぼありません。

## 端末ごとのグラフィック設定

| プリセット | 想定端末 | 内容 |
|---|---|---|
| ULTRA | 高性能PC | 影2048、フルブルーム、パーティクル4000、背びれ3列、ビル最大数 |
| HIGH | 標準PC・高性能スマホ | 影1024、半解像度ブルーム、パーティクル2600 |
| MEDIUM | 一般的なスマホ(iPhoneのAUTO設定) | 影1024、低解像度ブルーム、背びれ1列、近くのビル数を削減 |
| LOW | 低性能端末 | 影なし、ブルームなし、解像度0.9倍、演出を軽量化 |
