# ばあちゃんターボ

孫をせおったおばあちゃんが、時速100km超えで商店街を爆走する3Dランゲームです。iPhoneのSafari向け（PCでも遊べます）。

- 起動方法：リポジトリ直下で `python3 -m http.server 8000` を実行し、`http://localhost:8000/baachan/` を開くだけ。ビルド不要。
- GitHub Pages：`https://<ユーザー名>.github.io/godzilla-quiz/baachan/`
- iPhone：Safariの共有メニュー →「ホーム画面に追加」で全画面アプリとして起動できます。
- セーブ（ベスト記録）は端末内（localStorage）。広告・課金・外部通信なし。

## 操作

| 操作 | スマホ | PC |
|---|---|---|
| 車線を移動 | 左右にスワイプ（画面の左右をタップでも可） | ← → / A D |
| ジャンプ | 上にスワイプ（画面中央をタップでも可） | ↑ / W / スペース |
| しゃがむ | 下にスワイプ | ↓ / S |

「腰」が3つあり、障害物にぶつかるたびに1つ減ります。なくなると、ばあちゃんは座り込んでお茶にします。

## 笑えるところ

| 何が起きる | 内容 |
|---|---|
| ばあちゃんの名言 | 走りながら「ブレーキ？なにそれ」「昔は新幹線と競争したもんじゃ」など。孫は「ばあちゃん速すぎ！」とおびえ続けます。ブラウザの音声読み上げで、ばあちゃんがしゃべります（タイトルでOFFにできます）。 |
| 入れ歯 | ジャンプのたびに入れ歯が口から飛び出して戻ってきます。 |
| お茶ターボ | お茶の缶を取ると6秒間無敵の超加速。かんざしがプロペラになって回り、頭から湯気。軽トラもコーンも吹っ飛ばします。 |
| サラリーマン | ターボ中にぶつかると「ぶちょーーー！」と叫びながら空へ飛び、星になって「キラーン」。 |
| 入れ歯マグネット | 巨大な入れ歯がばあちゃんの頭上でカチカチ鳴り、あめちゃんを吸い寄せます。 |
| 特売 | 「たまご98円」の看板が近づくと、ばあちゃんが勝手にそっちへ吸い寄せられます。逆らっても「たまごーー！」と戻っていく。取ると孫がたまごを持たされ、次にぶつかると割れます。 |
| パトカー | 横に並んで「そこのおばあちゃん！止まりなさい！」。「わしは歩行者じゃ！」と言い返し、最後はパトカーがハトに囲まれて脱落。 |
| じいちゃん | ロケット付きシニアカー（ちゃんと歩道を走る）で「ばあさんや、お先に〜！」と抜いていく。ばあちゃんが「負けず嫌いモード」で加速し、じいちゃんはバッテリー切れ。 |
| ジャンプ台 | スローモーションで前方宙返り。孫は絶叫、着地すると審査員が点数を出します。 |
| ハト・ねこ | ハトの群れを突っ切ると羽が舞い、たまにハトがばあちゃんの頭に住みつく。横切るねこに近づくと、孫の頭にねこが乗ってしばらく一緒に走ります。 |
| 街のようす | 「整骨院 こしかた」「入れ歯 専門店」などの看板、「飛び出し注意（ばあちゃん）」の標識、手を振って応援する近所の人たち。 |
| 称号 | 走った距離で「近所のお散歩ばあちゃん」から「音速の老婆」「宇宙ばあちゃん」まで。 |

## しくみ

- `js/main.js`：ゲーム本体。3車線のランナー。街は40mごとのブロックを前方に作り、後ろを捨てます。障害物は「列」単位で出し、必ずどこか1車線は抜けられる（またはジャンプ・しゃがみで避けられる）ようにしています。パトカー・じいちゃん・特売・ジャンプ台・ねこは距離で起きるイベントです。
- `js/models.js`：ばあちゃん・孫・街並み・障害物をすべて three.js の基本図形で組み立てています（外部モデルなし）。看板の文字は canvas で描いたテクスチャ。
- `js/audio.js`：WebAudio で作った祭りばやし風のBGM（速度に合わせてテンポが上がる）と効果音。セリフは Web Speech API の読み上げ（声の高さをキャラごとに変えています）。
- `vendor/three.module.min.js`：three.js r169（MIT、`THREE-LICENSE.txt`）。
- `tools/make-icons.cjs`：タイトル画面を撮影してアイコンを作るスクリプト。
