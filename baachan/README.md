# ばあちゃんターボ

孫をせおったおばあちゃんが、町じゅうを自由に爆走して、目の前のものを片っぱしから吹っ飛ばす3Dゲームです。アイテムも障害物もゲームオーバーもありません。iPhoneのSafari向け（PCでも遊べます）。

- 起動方法：リポジトリ直下で `python3 -m http.server 8000` を実行し、`http://localhost:8000/baachan/` を開くだけ。ビルド不要。
- GitHub Pages：`https://<ユーザー名>.github.io/godzilla-quiz/baachan/`
- iPhone：Safariの共有メニュー →「ホーム画面に追加」で全画面アプリとして起動できます。
- セーブ（おもしろ実績・ハイスコア・選んだ背中と服）は端末内（localStorage）。広告・課金・外部通信なし。

## 遊び方

| 操作 | スマホ | PC |
|---|---|---|
| ハンドル | 画面をドラッグ（左右にずらした分だけ曲がる） | ← → / A D |
| ジャンプ | 上にすばやくはらう | スペース |
| お茶ブースト | 右下の 🍵 ボタン（6秒ごと） | Shift / ↑ / W |

ばあちゃんはずっと走り続けます。ぶつかった物は全部吹っ飛び、コンボがつながってゲージがたまり、満タンで「ばあちゃん覚醒」（金色・巨大化・衝撃波）。建物にぶつかっても「壁ドン！」と跳ね返るだけです。ハンドルをいっぱいに切ると「ばあちゃんドリフト」。

## 冒頭シーン

午前7時55分、ばあちゃんの家。孫が「ばあちゃん！学校に遅刻しちゃう！」と駆けこんでくる → お茶をすするばあちゃん → メガネがキラーン「…まかせとき。」→ 孫をせおって土煙とともに発進、タイトルがドーン。タップでスキップできます。

## おもしろ実績

「送迎完了…？」「おばちゃん軍団」「ラジオ体操ドミノ」「公務執行妨害」「壁ドン名人」「ばあちゃんドリフト」など全24個。集めた数に応じて、背中に乗せるもの（柴犬・ねこ・たぬきの置物・じいちゃん・部長・だるま）と服（ヒョウ柄・赤ジャージ・金ラメ）が解放されます。タイトル画面の実績パネルを押すと一覧が見られます。

## しくみ

- `models/*.glb`：ばあちゃん・孫・じいちゃん・シニアカー・パトカー・小学校・やぐら・銭湯・水筒・手ぬぐい・吹っ飛ばす小物などは、Blender の Python スクリプト `tools/make_models.py` で作ったオリジナル。手足・頭・入れ歯・メガネなど動く部分は別ノードで、原点が関節（正面 +Z、1単位 = 1m）。
  - 作り直し：`pip install bpy` のあと `python3 baachan/tools/make_models.py [--render] [名前...]`
- 町の建物・電柱・鳥居・社殿・木・テント・車・人などは、同じリポジトリの Blender 製モデル集 `../uminagi-assets/` を読み込み、マテリアルごとに BatchedMesh でまとめて描画（近くは詳細、遠くは軽いLOD、さらに遠くは非表示）。
- `js/world.js`：碁盤の目の町（4×4ブロック、道路、名所ブロック、建物の当たり判定）。`js/main.js`：操作・物理・吹っ飛ばし・イベント・冒頭シーン・ミニマップ。`js/fx.js`：破片・土煙・マンガ擬音・集中線。`js/save.js`：実績と解放。`js/audio.js`：BGM・効果音・セリフ読み上げ。
- 重い端末では、自動で解像度→影の順に下げます。
- `vendor/`：three.js r169（MIT、`THREE-LICENSE.txt`）と GLTFLoader・meshopt デコーダ・RoomEnvironment・BufferGeometryUtils。
