# ばあちゃんターボ

孫をせおったおばあちゃんが商店街を爆走し、目の前のものを片っぱしから吹っ飛ばす3Dランゲームです。iPhoneのSafari向け（PCでも遊べます）。

- 起動方法：リポジトリ直下で `python3 -m http.server 8000` を実行し、`http://localhost:8000/baachan/` を開くだけ。ビルド不要。
- GitHub Pages：`https://<ユーザー名>.github.io/godzilla-quiz/baachan/`
- iPhone：Safariの共有メニュー →「ホーム画面に追加」で全画面アプリとして起動できます。
- セーブ（段位・ミッション・ハイスコア・選んだ背中と服）は端末内（localStorage）。広告・課金・外部通信なし。

## 遊び方

| 操作 | スマホ | PC |
|---|---|---|
| 車線を移動 | 左右にスワイプ（画面の左右をタップでも可） | ← → / A D |
| ジャンプ | 上にスワイプ（画面中央をタップでも可） | ↑ / W / スペース |
| しゃがむ | 下にスワイプ | ↓ / S |

- **吹っ飛ばす**：コーン、ゴミ箱、みかん箱、だるま、信楽焼のたぬき、スイカ、自転車、ポスト、自販機、ハト、スマホを見ながら歩くサラリーマン。ぶつかるだけで、効果音と「ドカーン！」の文字と一緒に、回転しながら空へ飛んでいきます。
- **コンボ**：続けて吹っ飛ばすとコンボが伸び、10コンボごとに得点倍率が上がります（最大×5）。音程もだんだん上がります。
- **ばあちゃんゲージ → 覚醒**：吹っ飛ばす・ギリギリでよける・特売・ジャンプ台などでゲージがたまり、満タンで7秒間「覚醒」。ばあちゃんが金色に光って巨大化し、両腕を広げて突進、まわりの車線のものも衝撃波でまとめて飛ばします。軽トラや工事現場まで飛びます。
- **よけるもの**：軽トラ・軽自動車（車線を変える）、工事中のゲート（しゃがむ）、ガードレール（ジャンプ）。ぶつかると「腰」が1つ減り、コンボが途切れます。腰が3つなくなると終了。

## 段位とミッション（くり返し遊ぶしくみ）

段位ごとに3つのミッション（「1回で◯個吹っ飛ばす」「たぬきを◯体」「◯コンボ」「覚醒を◯回」「じいちゃんを吹っ飛ばす」など）があり、走っている最中に達成すると通知が出ます。3つそろうと、その回の結果画面で段位アップし、新しい乗客や服が解放されます。ミッションは段位ごとに決まっていて、段位が上がるほど目標が大きくなります。

## しくみ

- `models/*.glb`：ばあちゃん・孫・じいちゃん・シニアカー・パトカー・吹っ飛ばす小物・工事ゲート・特売ゲート・ジャンプ台などは、すべて Blender の Python スクリプト `tools/make_models.py` で作ったオリジナルです。手足・頭・入れ歯・メガネ・かんざしなど動かす部分は別ノードで、原点が関節の位置にあります（正面 +Z、1単位 = 1m）。
  - 作り直し：`pip install bpy` のあと `python3 baachan/tools/make_models.py [--render] [名前...]`（`--render` で `tools/preview/*.jpg` にプレビュー）
- 商店街の建物・電柱・街灯・のぼり・提灯・自販機・自転車・軽トラ・ねこ・柴犬などは、同じリポジトリの Blender 製モデル集 `../uminagi-assets/` をそのまま読み込んでいます（建物と街の小物はインスタンス描画、遠くは軽いLODモデル）。
- `js/main.js`：ゲーム本体（3車線ランナー、吹っ飛ばしの物理、ヒットストップ、コンボ・覚醒、イベント、ミッション判定）。
- `js/world.js`：道路・歩道・建物の並び・空と光。`js/fx.js`：破片・土煙・マンガの擬音文字・集中線。`js/save.js`：段位・ミッション・解放。`js/audio.js`：祭りばやし風BGM（覚醒中は音が厚くなる）と効果音、Web Speech API のセリフ読み上げ。
- `vendor/`：three.js r169（MIT、`THREE-LICENSE.txt`）と GLTFLoader・meshopt デコーダ・RoomEnvironment。
