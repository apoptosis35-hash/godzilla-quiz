# マッハ突破（SONIC BREAKER）

音速の壁を突き破る3Dフライトゲーム。岩の柱や鉄骨をよけながら、どこまで速く・遠くまで飛べるかを競います。

- 起動方法：リポジトリ直下で `python3 -m http.server 8000` を実行し、`http://localhost:8000/mach/` を開く。ビルド不要。
- 3D描画は three.js（r169、`vendor/` に同梱）。機体も地形もすべてコード上の図形です。
- GitHub Pages：`https://<ユーザー名>.github.io/godzilla-quiz/mach/`
- ベスト記録は端末内（localStorage）に保存。

## 操作

| 操作 | スマホ | PC |
|---|---|---|
| 操縦（上下左右） | 画面をドラッグ（バーチャルスティック） | 矢印キー / WASD / マウスドラッグ |
| ブースト | 右下の BOOST ボタンを押しっぱなし | スペース / Shift |

## ルール

- 何もしなくても少しずつ加速。ブーストでぐんぐん加速（ゲージを消費、ゆっくり回復）
- 水色のリングをくぐるとブーストゲージ回復＋スピードアップ
- 岩の柱・黄色と黒の鉄骨・地面にぶつかったら墜落
- 速くなるほど障害物の間隔は広がるが、迫ってくるのも速い。横の動きも速度に応じて速くなる

## マッハの演出

- マッハ1、2、3…と節目を越えるたびに **ソニックブーム**：衝撃波の輪、白いフラッシュ、画面の揺れ、「ドドン」という2連の爆音
- 音速の手前では機体のまわりに白い **ベイパーコーン** ができる
- 音速を超えるとエンジン音がこもる（自分の音を追い越すから）
- 速度が上がるほど視野角が広がり、スピード線が伸びる
- 空の色が マッハ0 の青空 → マッハ6 の紫 → マッハ10 の宇宙のような黒へ。星も見えてくる

最高速度で称号が決まります：亜音速パイロット → 音の壁を越えし者 → 超音速パイロット → マッハの申し子 → 極超音速の鬼 → 人間をやめた人 → 流れ星。
