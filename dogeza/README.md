# 全力土下座

上司のプリンを食べてしまったあなた。長押しで「謝罪力」を溜めて、離して土下座する3Dおバカゲームです。強すぎると床を突き抜けて、地球の裏側まで行ってしまいます。

- 起動方法：リポジトリ直下で `python3 -m http.server 8000` を実行し、`http://localhost:8000/dogeza/` を開くだけ。ビルド不要。
  - ES Modules を使うので、`index.html` を直接ダブルクリックでは動きません（ローカルサーバー経由で開いてください）。
- 3D描画は three.js（r169、`vendor/` に同梱）。キャラ・部屋・地下はすべてコード上の図形で作っていて、モデルファイルはありません。
- GitHub Pages：`https://<ユーザー名>.github.io/godzilla-quiz/dogeza/`
- スマホ・PCどちらでも遊べます。ハイスコアは端末内（localStorage）に保存。

## 遊び方

| 操作 | スマホ | PC |
|---|---|---|
| 謝罪力を溜める | 画面を長押し | スペース / Enter を押しっぱなし |
| 土下座する | 指を離す | キーを離す |

ゲージは行ったり来たりします。**緑のところ**で離せば許されます。真ん中に近いほど高得点で、ど真ん中なら「神土下座」（2倍）。

- 弱すぎる → 「それは会釈だ！」
- 強すぎる → 床にめり込む。強ければ強いほど深く「床下 → 地下駐車場 → 地下鉄のトンネル → 温泉 → マントル → 地球の核」まで落ちていく
- **98%以上** → 地球を突き抜けてブラジルへ。地球の裏側の人に謝ってしまい、なぜか許される（+300点ボーナス）

失敗するたびに胃薬が1つ減って、3回で「胃が限界です」。許された罪の数で謝罪ランク（謝罪ビギナー〜神をも謝らせる者）が決まります。

## 罪と相手

相手は部長 → 社長 → 会長 → 総理大臣 → 宇宙人 → 神 と出世していき、罪もどんどんスケールが大きくなります（社長のカツラを扇風機で飛ばした、UFOに「月極駐車場」の看板を立てた…）。最後は「神様のプリンを食べた」。その後は延々とプリンを食べ続けます。

土下座も進化します：ふつうの土下座 → ジャンピング土下座 → 回転土下座 → トリプルアクセル土下座 → 分身土下座 → 大気圏突入土下座。後半ほどゲージが速く、緑が狭くなります。

## 3Dの見どころ

- 溜めるとカメラが寄っていき、ゲージ満タン付近で画面が震えてスーツが赤く光る
- 神土下座では紙吹雪の中をカメラがぐるっと回り、上司が泣く
- 社長が驚くとカツラが飛ぶ
- 突き抜けると、カメラが断面図のような地層を追いかけて落ちていく（駐車場の車、地下鉄、温泉、マントル…）
- ブラジルに着くと、カメラが180度回転して地球の裏側が「上」になる。現地の人が歓迎してくれる

効果音はWeb Audio、謝罪ボイスはブラウザの読み上げ（日本語音声がある端末のみ）。右上のボタンでミュートできます。
